# 织梦平台定位
主要面向女性用户的一站式个性化服装设计+学习+创作者变现平台，以“人人皆可参与设计、按需生产零库存”为核心，打通“学习-设计-生产-变现”全链路，区别于SHEIN的快时尚批量模式，主打高品质定制化、用户共创生态与低门槛创作体验。

# 目标用户画像
- 普通女性消费者：追求个性化穿搭、不愿撞衫，对服装品质有要求，愿意为定制化设计支付合理溢价，而且对于已经打版好的衣物不支持退货。
- 设计爱好者/小白创作者：对服装设计感兴趣但缺乏专业技能和供应链资源，希望通过设计作品获得额外收入，愿意免费学习相关知识。
- 专业设计师/小微品牌主理人：有设计能力和相关资质，希望获得低成本的供应链支持和流量曝光，孵化个人品牌。

# 核心功能模块
## 用户个人信息管理模块
- 体型数据采集：支持两种方式，一是手动输入身高、体重、三围、肩宽、臂长等12项核心体型指标，二是通过AI拍照量体（拍摄正面、侧面、背面3张照片，自动识别100+身体数据点，精度控制在3mm内），数据加密存储，用于后续定制服装的版型匹配。
- 偏好以及收藏管理：设计元素标签，收藏达人主页等，例如给用户的推文贴一些设计标签，以及支持收藏、转发等

## 学习以及创作模块
- 免费学习中心：提供从服装设计基础、面料知识、打版技巧到软件操作的阶梯式免费教程，配套案例拆解、实操练习，用户完成学习可获得“设计能力认证”，解锁更多高级设计工具权限。
- 参数化设计工具：用户可自主选择服装品类（连衣裙、衬衫、半裙、外套等），从款式（领型、袖型、版型、裙长等18类可调节元素）、材质（棉麻、真丝、羊毛、科技面料等100+种可选面料）、颜色、图案、细节装饰（纽扣、刺绣、蕾丝等）等维度自由组合设计，对比市面上主流的服装设计软件。
- AI辅助设计：支持文字描述生成设计稿（如输入“适合约会的法式碎花泡泡袖连衣裙”即可生成5款候选方案）、手绘草图自动优化、参考图风格融合功能，AI会根据用户体型数据自动调整版型参数，实现“一人一版”。
- 3D虚拟试衣：生成与用户身材、长相接近的虚拟形象，实时预览设计效果，可调整面料垂坠感、动态展示效果，确认满意后再下单生产。

## 创作者生态与变现模块
- 作品发榜与投票：用户可将设计作品发布到平台榜单，其他用户可浏览、投票、收藏，每周/每月更新热度榜单。
个性化推荐：AI持续学习用户的浏览、收藏、购买、设计行为，自动推荐匹配用户偏好的设计思路、面料款式、热门榜单作品，随着使用时长增加，推荐精准度持续提升。
- 趋势预测：结合社交媒体流行元素、季节变化、用户群体偏好，定期推送设计趋势报告，辅助创作者优化设计方向。
佣金结算规则：进入投票前1000名且作品对应订单退货率低于10%的设计师，可按订单数的8%-12%抽取佣金（根据品类、订单量阶梯调整），佣金T+7结算到个人账户。
- 品牌孵化通道：拥有相关资质（设计专利、营业执照等）和运营团队的用户，可申请创建个人品牌，平台提供供应链支持、流量扶持、品牌运营指导，品牌方可自主定价、管理店铺。

## 供应链与订单模块
- C2M按需生产：用户下单后订单直接对接合作的柔性工厂，无中间库存环节，生产周期7-15天，工厂可根据设计稿自动生成版型、排料生产，面料直采降低成本。
- 全流程跟踪：用户可实时查看订单的生产进度、质检报告、物流信息，支持退货售后，退货率数据实时同步到创作者后台。

- 广场：推荐/关注/热门信息流、推文详情、发布（关联作品/标签）、搜索
- 榜单：周/月/总榜、筛选、每日 10 票、热度算法；作品详情：3D 预览模拟、6 背景切换、一键适配体模、智能尺码
- 学习中心：阶梯课程、视频播放模拟、能力认证、创作者上传教程
- 商城：Banner/品类/瀑布流、购物车、结算（体型确认 + 定制条款）、订单全流程跟踪（状态时间轴/生产进度/质检报告/物流）、售后
- 我的：体型数据（手动 12 项/AI 拍照模拟）、偏好收藏、**作品集（导入设计师App同步码）**、创作者后台（SVG KPI 图表）、佣金提现、品牌孵化

## 服装设计师App（designer）— 对标市场工具的创作端

信息架构以「画布」为核心，参数化仅是「3D 模拟」里的功能之一：

- **创作链路工作台（/design/pipeline，核心）**：①灵感 → ②2D版片（6品类纸样版片、拖拽手柄改衣长/腰围松量/摆量、尺寸标注实时、放码/缝份/纱向）→ ③3D联动（**2D⇄3D 双向实时**：改版片手柄 3D 同步、3D 滑杆反向回版片）→ ④交付（工艺单 TechPack + 版片清单工件稿 + 导出/同步官方App）——极速验证、减少实物样衣
- **首页（项目中心）**：创作链路入口、2D 画布 / 3D 模拟双入口、最近项目（2D+3D 混合）、模板速建、AI 灵感工坊、趋势灵感
- **2D 画布**：人体模板（正/背面）与平铺模板（连衣裙/半裙/衬衫/裤装）起稿；自由笔触（颜色/粗细/橡皮/撤销）；区域填充（纯色/面料/图案）；标注；自动草稿
- **素材库**：面料（克重 + 垂坠/光泽/弹性）、图案、辅料（纽扣/拉链/蕾丝/珍珠）、色卡
- **3D 模拟**：参数化建模（6 品类 × 18 类款式元素 + AI 工具箱：文生图 5 款候选/草图优化/风格融合/一人一版）+ 3D 试衣（体型人台/6 场景/动态动画）
- **作品 + 工艺单**：3D/2D 稿管理；一键生成工艺单 Tech Pack（BOM/尺寸表/规格/工艺步骤，直连柔性工厂）；同步至官方App（同步码）
