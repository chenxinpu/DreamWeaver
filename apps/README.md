# apps · 织梦双应用架构

本目录包含织梦生态的**两个独立应用**（对应《织梦PRD.md》与《服装设计App产品需求文档.docx》两份 PRD）：

| 应用 | 目录 | dev 端口 | 定位 |
|---|---|---|---|
| **织梦 · 官方平台App** | [`official/`](official) | 5173 | 内容社区（广场/榜单）+ 学习中心 + 商城交易 + C2M 订单跟踪（生产进度/质检/物流）+ 个人中心 + 创作者后台 KPI |
| **织梦 · 服装设计师App** | [`designer/`](designer) | 5174 | 独立创作工具端：**2D 画布绘制**（人体/平铺模板）+ 素材库 + **3D 模拟**（参数化建模/试衣）+ 工艺单 Tech Pack |

> 拆分理由：创作工具对交互深度与算力要求高（对标 CLO 3D / Style3D / Prêt-à-Template），应独立成 App。
> 跨端协同：设计稿以**参数 JSON**存储 → 双端同一渲染引擎（DressCanvas）保证「参数化跨端一致」；原型用**同步码**演示跨端同步（设计师App导出 → 官方App「作品集 → 导入设计稿」），正式版走云端 design-service。

## 快速开始

```bash
# 织梦官方平台App
cd official && npm install && npm run dev     # http://localhost:5173

# 织梦服装设计师App
cd designer && npm install && npm run dev     # http://localhost:5174
```

各自 `npm run build` 独立产出 `dist/`，可分开部署。

## 官方平台App（official）— 电商 · 社区 · 学习 · 履约

- 广场：推荐/关注/热门信息流、推文详情、发布（关联作品/标签）、搜索
- 榜单：周/月/总榜、筛选、每日 10 票、热度算法；作品详情：3D 预览模拟、6 背景切换、一键适配体模、智能尺码
- 学习中心：阶梯课程、视频播放模拟、能力认证、创作者上传教程
- 商城：Banner/品类/瀑布流、购物车、结算（体型确认 + 定制条款）、订单全流程跟踪（状态时间轴/生产进度/质检报告/物流）、售后
- 我的：体型数据（手动 12 项/AI 拍照模拟）、偏好收藏、**作品集（导入设计师App同步码）**、创作者后台（SVG KPI 图表）、佣金提现、品牌孵化

## 服装设计师App（designer）— 对标市场工具的创作端

信息架构以「画布」为核心，参数化仅是「3D 模拟」里的功能之一：

- **首页（项目中心）**：2D 画布 / 3D 模拟双入口、最近项目（2D+3D 混合）、模板速建、AI 灵感工坊、趋势灵感
- **2D 画布**：人体模板（正/背面）与平铺模板（连衣裙/半裙/衬衫/裤装）起稿；自由笔触（颜色/粗细/橡皮/撤销）；区域填充（纯色/面料/图案）；标注；自动草稿
- **素材库**：面料（克重 + 垂坠/光泽/弹性）、图案、辅料（纽扣/拉链/蕾丝/珍珠）、色卡
- **3D 模拟**：参数化建模（6 品类 × 18 类款式元素 + AI 工具箱：文生图 5 款候选/草图优化/风格融合/一人一版）+ 3D 试衣（体型人台/6 场景/动态动画）
- **作品 + 工艺单**：3D/2D 稿管理；一键生成工艺单 Tech Pack（BOM/尺寸表/规格/工艺步骤，直连柔性工厂）；同步至官方App（同步码）

## 技术说明

- React 19 + TypeScript + Vite；无 UI 库依赖（纯 CSS 设计系统 + 行内 SVG）；移动优先（430px 手机壳）
- 服装渲染：参数化 SVG 引擎（`designer/src/components/design/DressCanvas.tsx`，18 类元素实时重建几何 + 面料物理参数）；生产级可替换为 glTF + 原生引擎（SceneKit/Filament）
- 数据为前端 mock（localStorage 持久化），交互层可对接 PRD 的 `/api/v1/*` 与 design-service / render-service
- 自动化验证：仓库根 `tools/screenshot/`（Playwright QA/冒烟/截图，`pages-official.csv` / `pages-designer.csv`）
