# 服装设计App产品需求文档（PRD）

## 一、文档概述

### 1.1 文档信息表

| 项目名称 | 服装设计App | 文档版本 | V1.0.0 |
|:---:|:---:|:---:|:---:|
| 文档状态 | 初稿 | 编写日期 | 2026-09-01 |
| 目标平台 | iOS / Android / HarmonyOS | 产品定位 | 一站式个性化服装设计创作工具 |

### 1.2 项目背景

在"人人皆可参与设计、按需生产零库存"的平台战略下，官方平台App承载了交易、社区、订单等核心闭环功能。然而，服装设计与3D渲染对设备算力、交互深度及专业工具链有极高要求。为提供媲美桌面级专业软件（如CLO 3D）的创作体验，需剥离重型创作功能，构建独立的"服装设计App"。该App作为平台的"设计创作工具端"，专注于参数化建模、AI辅助生成与3D虚拟试衣，最终通过云端同步将设计资产无缝流转至官方平台App进行生产与变现。

### 1.3 术语定义表

| 术语 | 定义说明 |
|:---|:---|
| 参数化设计 | 通过调节数值或枚举值（如领深、袖长）驱动3D模型自动重建的设计方式。 |
| 一人一版 | 基于用户个人体型数据，AI自动调整版型参数，生成专属定制版型的技术。 |
| 质点弹簧模型 | 一种用于模拟布料物理特性（如垂坠、拉伸）的3D渲染算法。 |
| 虚拟人台 | 基于用户真实体型数据生成的3D数字替身，用于实时试衣预览。 |

## 二、产品定位与核心目标

### 2.1 产品定位

服装设计App是平台生态中的"设计创作工具端"，对标CLO 3D与Adobe Illustrator，但降低了专业门槛。它通过"参数化+AI+3D"三位一体的工具链，赋能零基础爱好者与专业设计师，打通从灵感、设计到3D验证的轻量化创作闭环。

### 2.2 核心目标表

| 目标维度 | 核心指标 | 目标值（V1.0上线3个月） |
|:---|:---|:---|
| 用户增长 | 设计App独立注册用户数 | 50,000 |
| 创作活跃 | 月均活跃创作者（MAU） | 15,000 |
| 作品产出 | 月均新增有效设计稿 | 30,000 |
| 跨端同步 | 作品成功同步至官方App转化率 | > 60% |

## 三、用户画像与使用场景

### 3.1 核心用户画像

- **设计爱好者/小白创作者**：年龄18-30岁女性。无专业制版基础，但具备审美与表达欲。核心诉求是"所想即所见"，依赖AI辅助与模板快速出图，追求3D试衣的趣味性。
- **专业设计师/小微品牌主理人**：年龄25-40岁。具备服装专业知识。核心诉求是"高效打版与面料验证"，依赖参数化工具精准调节18类款式元素，需要导出符合生产标准的版型数据。

### 3.2 核心使用场景表

| 场景编号 | 场景名称 | 用户行为与痛点 | 解决方案 |
|:---:|:---|:---|:---|
| S-01 | 参数化款式定制 | 用户想修改连衣裙领型，传统软件需重新建模。 | 在参数面板下拉选择"V领"，3D模型实时无缝切换。 |
| S-02 | AI灵感生成 | 用户有"法式碎花泡泡袖"灵感但不会画。 | 输入Prompt，AI生成5款候选方案，一键应用至工作台。 |
| S-03 | 手绘草图转稿 | 用户在纸上画了草图，无法变成数字资产。 | 拍照上传，AI自动识别线条并优化为专业设计稿。 |
| S-04 | 3D虚拟试衣 | 担心设计上身效果，不敢盲目下单生产。 | 生成专属虚拟人台，实时预览面料垂坠感与动态效果。 |
| S-05 | 参考图风格融合 | 喜欢某张网图的配色与肌理，想用到自己的设计中。 | 上传参考图，AI提取风格并融合至当前服装材质上。 |
| S-06 | 作品一键上架 | 设计完成后，需在多个App间切换上传。 | 点击"同步至官方App"，设计稿与3D预览自动发布。 |

## 四、功能模块详细说明

### 4.1 整体信息架构

```
服装设计App
├── 首页 (灵感推荐、热门模板、AI创作入口)
├── 设计工作台 (核心创作区)
│    ├── 3D设计画布
│    ├── 参数化调节面板
│    ├── AI辅助工具箱
│    └── 素材/面料库
├── 3D试衣间 (虚拟人台、动态展示)
├── 我的作品 (草稿、已发布、版本历史)
└── 学习中心 (视频教程、工具指南、灵感库)
```

### 4.2 设计工作台（核心模块）

- **功能说明**：提供类似桌面级CAD的移动端创作环境，支持所见即所得的参数化编辑。
- **页面结构**：
  - **设计画布**：占据屏幕核心区域，支持双指缩放、3D旋转、手势交互。
  - **参数面板**：底部/侧边抽屉式面板，按模块分类展示可调节属性。
  - **工具栏**：顶部悬浮，包含撤销/重做、AI生成、3D试衣、保存/同步。
  - **素材库**：右侧/底部滑动列表，支持面料、图案、装饰件的拖拽应用。
- **参数化设计工具详细说明**：
  - **服装品类选择**：连衣裙、衬衫、半裙、外套、裤装、套装。切换品类时，参数面板自动适配对应结构。
  - **18类可调节款式元素**：
    1. 领型：圆领、V领、方领、一字领、立领等。
    2. 袖型：无袖、短袖、泡泡袖、灯笼袖、喇叭袖等。
    3. 版型：紧身、合体、宽松、A字、H型等。
    4. 裙长/衣长：超短、及膝、中长、及踝等（支持精确cm调节）。
    5. 腰型：高腰、中腰、低腰、松紧腰等。
    6. 门襟：单排扣、双排扣、暗门襟、系带等。
    7. 口袋：贴袋、插袋、挖袋、无口袋等。
    8. 下摆：平摆、圆摆、开衩摆、不规则摆等。
    9. 肩线：正常肩、落肩、插肩、垫肩等。
    10. 省道：胸省、腰省、肩省、无省等。
    11. 褶皱：自然褶、压褶、抽褶、无褶等。
    12. 开衩：前开衩、后开衩、侧开衩、不开衩等。
    13. 装饰：刺绣、蕾丝拼接、荷叶边、绑带等。
    14. 里衬：全里衬、半里衬、无里衬等。
    15. 缝线：明线、暗缝、撞色线等。
    16. 扣子：树脂扣、金属扣、包布扣、无扣等。
    17. 拉链：隐形拉链、金属拉链、无拉链等。
    18. 印花位置：满印、居中、下摆、局部等。
  - **材质选择**：内置100+种面料，涵盖棉麻、真丝、羊毛、科技面料等，每种面料绑定真实的物理参数（克重、摩擦系数、弯曲刚度）。
  - **颜色/图案/细节装饰**：支持RGB/HEX取色，图案支持平铺、拉伸、居中适配，装饰件支持位置微调。
- **设计历史记录与版本管理**：自动保存编辑快照，支持一键回退至任意历史节点，防止误操作丢失灵感。

### 4.3 AI辅助设计模块

- **文字生成设计稿**：
  - **交互流程**：点击AI工具箱 → 输入Prompt（如"适合约会的法式碎花泡泡袖连衣裙"）→ 点击生成 → 展示5款候选3D预览 → 点击"应用"载入工作台。
- **手绘草图自动优化**：
  - **交互流程**：拍照/相册导入手绘图 → AI识别线稿结构 → 生成优化后的专业设计稿 → 用户确认并替换当前模型。
- **参考图风格融合**：
  - **交互流程**：上传参考图 → AI提取色彩、纹理、风格特征 → 预览融合效果 → 确认应用至当前服装。
- **AI版型适配**：
  - **交互流程**：首次使用引导录入体型数据（身高、体重、三围等）→ AI基于数据自动计算并调整18类款式元素的默认值 → 实现"一人一版"的精准合体。

### 4.4 3D虚拟试衣模块

- **虚拟形象生成**：基于用户填写的体型数据与正面/侧面照片，生成高逼真度的3D人台。
- **实时3D预览**：设计工作台中的任何参数修改，均在3D画布中以<100ms延迟实时渲染。
- **面料物理模拟**：支持调节面料的垂坠感、弹性、光泽度，真实还原真丝的飘逸与羊毛的挺括。
- **动态展示**：内置行走、转身、摆裙等动画预设，支持360°自由旋转查看。
- **背景切换**：提供纯色、摄影棚、户外等多种背景，便于截图分享。
- **3D渲染性能优化策略**：采用LOD（多细节层次）技术，编辑时加载低模保证帧率，截图/导出时切换高模；利用移动端GPU硬件加速。

### 4.5 素材库模块

- **面料素材**：100+种面料贴图，支持PBR材质参数预设，真实还原光影。
- **图案素材**：碎花、条纹、格子、几何等矢量图案，支持无缝平铺与自由缩放。
- **装饰素材**：纽扣、刺绣、蕾丝、珠片等3D模型，支持拖拽吸附至指定位置。
- **模板库**：官方与达人预设款式模板，支持"一键套用+二次修改"。

### 4.6 作品管理模块

- **我的作品列表**：按时间/状态分类，支持缩略图预览与批量管理。
- **作品详情**：展示3D预览、完整参数配置、版本历史，支持直接编辑。
- **上传到官方App**：一键同步设计稿、3D预览图、参数说明至官方App个人作品页。
- **作品分享**：生成带3D预览链接的分享卡片，支持分享至微信、小红书等社交平台。

### 4.7 学习模块（App内嵌）

- **设计教程**：从基础参数调节到AI进阶玩法的视频教程。
- **工具使用指南**：交互式新手引导，边学边练。
- **设计灵感库**：聚合热门设计趋势、配色方案、面料搭配参考。

## 六、技术架构设计

### 6.1 整体技术架构

```
[客户端层] iOS / Android / HarmonyOS (原生 + 3D引擎)
      |
[网关层] API Gateway (鉴权、限流、路由)
      |
[微服务层]
├── 设计服务 (参数化引擎、版本管理)
├── AI推理服务 (文生图、草图优化、风格融合)
├── 3D渲染服务 (人台生成、面料模拟、云端渲染)
└── 用户/作品服务 (同步、分享、素材管理)
      |
[数据层] MySQL (业务数据) | MongoDB (版本/素材) | OSS (3D模型/贴图) | Redis (缓存)
```

### 6.2 客户端技术选型

| 平台 | 技术栈 | 选型理由 |
|:---|:---|:---|
| iOS | Swift + SceneKit | 苹果原生3D引擎，性能最优，与iOS生态深度集成。 |
| Android | Kotlin + Filament | 谷歌开源PBR渲染引擎，轻量级，跨Android版本兼容性好。 |
| HarmonyOS | ArkTS + 3D Kit | 鸿蒙原生3D能力，支持分布式流转。 |

- **客户端分层架构**：UI层（SwiftUI/Jetpack Compose）→ 业务逻辑层（MVVM）→ 3D引擎层（SceneKit/Filament）→ 底层渲染接口（Metal/Vulkan）。
- **关键技术细节**：
  - **状态管理**：采用响应式框架（Combine/Flow），确保参数修改与3D视图实时双向绑定。
  - **网络层**：基于Retrofit/Alamofire封装，支持大文件（3D模型/贴图）分片上传与断点续传。
  - **本地存储**：SQLite存储设计草稿元数据，文件系统缓存3D资产，支持离线编辑。
  - **3D渲染引擎**：移动端选用原生引擎（SceneKit/Filament）而非Unity/Three.js，以减小包体积并提升渲染帧率。
  - **参数化建模引擎**：采用拓扑变形（Topology Morphing）技术，预置基础网格，通过骨骼与BlendShape驱动18类元素的无缝切换。
  - **AI推理**：端侧部署轻量级模型处理实时预览，复杂生成（文生图、风格融合）调用云侧GPU集群。

### 6.3 后端技术架构

- **微服务划分表**：

| 服务名称 | 职责 | 技术栈 | 数据库 |
|:---|:---|:---|:---|
| design-service | 作品CRUD、参数解析、版本管理 | Spring Boot | MySQL + MongoDB |
| ai-service | AI生成任务调度、模型推理 | Python/FastAPI | Redis + PostgreSQL |
| render-service | 3D人台生成、面料物理模拟 | C++/gRPC | OSS |
| user-service | 用户信息、体型数据、跨端同步 | Spring Boot | MySQL |

- **服务通信方式**：同步接口采用RESTful/gRPC，异步任务（AI生成、3D渲染）采用RabbitMQ消息队列。
- **数据库设计（MySQL核心表DDL）**：

```sql
-- 设计作品表
CREATE TABLE design_works (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    title VARCHAR(255) NOT NULL,
    category ENUM('DRESS','SHIRT','SKIRT','COAT','PANTS','SUIT') NOT NULL,
    thumbnail_url VARCHAR(512),
    model_3d_url VARCHAR(512),
    status TINYINT DEFAULT 0 COMMENT '0:草稿 1:已发布',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id)
);

-- 设计参数表
CREATE TABLE design_parameters (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    work_id BIGINT NOT NULL,
    version INT NOT NULL,
    params_json JSON NOT NULL COMMENT '18类款式元素及面料参数',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_work_version (work_id, version)
);

-- 3D模型资产表
CREATE TABLE design_3d_assets (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    work_id BIGINT NOT NULL,
    asset_type ENUM('MODEL','TEXTURE','DECOR') NOT NULL,
    file_url VARCHAR(512) NOT NULL,
    file_hash VARCHAR(64) NOT NULL,
    file_size BIGINT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- AI生成记录表
CREATE TABLE ai_generation_logs (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    task_type ENUM('TEXT_TO_DESIGN','SKETCH_OPTIMIZE','STYLE_FUSION') NOT NULL,
    prompt TEXT,
    result_urls JSON COMMENT '生成的候选方案URL列表',
    status TINYINT COMMENT '0:处理中 1:成功 2:失败',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

- **MongoDB集合设计**：
  - **design_versions**：存储设计稿的完整快照（含参数、素材引用、3D状态），支持无限版本回溯。
  - **material_library**：存储面料元数据、PBR贴图路径、物理参数预设，支持高频读取与灵活扩展。

### 6.4 关键技术实现方案

- **参数化设计引擎**：采用"基础版型+拓扑变形"方案。预置6大品类的基础网格，18类元素通过BlendShape权重与骨骼变换驱动，避免实时布尔运算导致的性能瓶颈。
- **AI辅助设计**：
  - 文字生成：基于Stable Diffusion微调的服装垂直模型，输出ControlNet深度图作为3D重建引导。
  - 手绘优化：采用Line2Mesh算法，将2D线稿转化为3D网格，再通过AI纹理生成补全细节。
  - 风格融合：基于IP-Adapter技术，提取参考图风格特征并注入生成模型。
- **3D虚拟试衣**：
  - 体模生成：基于SMPL-X人体模型，通过少量照片拟合用户体型参数。
  - 面料模拟：采用质点弹簧模型（Mass-Spring System），在移动端GPU上实现实时物理结算。
  - 实时渲染：利用PBR材质管线与IBL环境光，确保面料光泽与垂坠感真实。
- **跨端3D渲染同步**：设计参数以JSON格式存储，各端原生引擎根据参数独立重建3D场景，确保跨端一致性。

## 七、接口设计规范

### 7.1 接口规范总则

- 协议：HTTPS
- 数据格式：JSON
- 鉴权：Bearer Token (JWT)
- 版本控制：URL路径 /api/v1/
- 错误码：统一使用HTTP状态码 + 业务错误码

### 7.2 核心接口列表

| 模块 | 接口名 | 方法 | 路径 | 说明 |
|:---|:---|:---|:---|:---|
| 设计工作台 | 创建作品 | POST | /api/v1/works | 新建设计草稿 |
| 设计工作台 | 保存参数 | PUT | /api/v1/works/{id}/params | 保存18类款式参数 |
| 设计工作台 | 获取素材列表 | GET | /api/v1/materials | 分页获取面料/图案/装饰 |
| AI辅助 | 文字生成设计 | POST | /api/v1/ai/text-to-design | 提交Prompt生成任务 |
| AI辅助 | 查询生成结果 | GET | /api/v1/ai/tasks/{taskId} | 轮询/WebSocket获取结果 |
| AI辅助 | 手绘草图优化 | POST | /api/v1/ai/sketch-optimize | 上传图片优化 |

## 八、非功能需求

### 8.1 性能指标

- 冷启动时间：< 2秒
- 3D渲染帧率：编辑状态 ≥ 30fps，试衣状态 ≥ 45fps
- AI生成响应：文字生成 < 8秒，手绘优化 < 5秒
- 参数调节延迟：< 100ms

### 8.2 安全要求

- 用户体型数据与照片加密存储，仅用于3D人台生成，不对外暴露。
- 设计作品版权保护，上传时自动添加数字水印。
- API接口全链路HTTPS，敏感操作二次验证。

### 8.3 可用性要求

- 核心服务可用性 ≥ 99.9%
- AI推理服务支持弹性伸缩，应对突发流量。

### 8.4 兼容性要求

- iOS：iPhone 11及以上，iOS 15+
- Android：骁龙86
